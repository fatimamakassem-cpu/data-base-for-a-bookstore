# data-base-for-a-bookstore
SQL Data Analysis &amp; Database management System
- Schema Design & DDL: Created a relational database (store) from scratch comprising 8 interconnected tables.
- Data Integrity: Enforced business rules using Primary Keys, Foreign Keys, UNIQUE, CHECK, and DEFAULT constraints.
- Analytical Querying: Executed multi-table joins, subqueries, Common Table Expressions (CTEs), and window functions.
- Database Optimization: Implemented non-clustered indexes and SQL Views to enhance retrieval speed and simplify complex analytical queries.
